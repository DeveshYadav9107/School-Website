# RMS World School — Official School Website 🎓

A modern, responsive, and interactive website for **RMS World School**, located at **11th Milestone, Rewari-Shahjahanpur Road, Sulkha (Haryana)** following **CBSE Norms & Curriculum**.

Built with **React 19**, **Next.js 16 (App Router)**, **Tailwind CSS**, and **pure JavaScript (JSX/JS)**.

---

## 🌟 Key Features

1. **Brand Identity & Royal Academic Crest:**
   - Custom inline SVG shield crest in Classic Dark Navy Blue (`#0B2545`) and Antique Gold (`#C5A059`) featuring an open book beneath 5 small stars, bold **"RMS"** lettering, and a gold ribbon banner at the base.
2. **Top Utility Strip & Glassmorphism Navbar:**
   - Admissions 2027-28 ticker, CBSE Norms & Curriculum badge, clickable phone helplines (`+91 9728035202`, `+91 7988720175`), and "Parent ERP Login" trigger.
   - Sticky navbar with smooth glassmorphism transition on scroll, active indicator bar, mobile drawer, and dedicated **Careers** navigation tab.
3. **Faculty Recruitment & Walk-In Interview Portal (`/careers`):**
   - Dedicated recruitment highlight banner on the Home page plus full **Careers** section.
   - Navy & Gold Walk-In Interview Event Card (Sunday, 6th December 2026) with click-to-call inquiry buttons (`9728035202`, `7988720175`), Calendar Reminder toggle toast, and `"Salary No Bar for Deserving Candidates | Qualification as per CBSE Norms"`.
   - Category filterable positions grid (`All`, `Academic Faculty`, `Support & Co-Curricular`) covering Coaching Faculty, PGT (11 subjects), TGT & Coordinator, PRT, Mother Teacher (LKG to 2nd Class), and Co-Curricular/Support Staff.
   - Interactive **Quick Apply / Pre-Register for Walk-In Modal** with role pre-fill, dynamic PGT Subject dropdown, form validation, and instant printable **Walk-In Interview Pass (`RMS-2026-XXXX`)**.
4. **Hero Section & Key Metrics:**
   - Architectural campus banner with smooth hover zoom, dual CTAs, Walk-In quick badge, and admissions desk overview card.
   - 4-column metrics: 28+ Years of Excellence, 15:1 Student-Teacher Ratio, 100% CBSE Pass Rate, and 18-Acre Green Campus.
5. **Academic Wings, Notice Board & Facilities:**
   - Interactive curriculum wings, categorized notices with **Official School Circular modal viewer**, upcoming events calendar with toast reminders, campus facilities cards, and testimonial carousel.
6. **Admissions Fee Estimator (₹ INR) & Enquiry Form:**
   - Dynamic annual & quarterly fee breakdown calculator + online enquiry form generating `RMS-2027-XXXX` application slips.
7. **Filterable Photo Gallery & CBSE Mandatory Disclosure:**
   - 5-category gallery with full-screen keyboard-accessible Lightbox.
   - Appendix-IX Mandatory Disclosure tables with printable **certified document preview modals** and board result archives.
8. **Parent ERP Portal (Demo Mode) & Help Assistant:**
   - One-click demo credentials autofill, student dashboard, electronic fee receipt printer, floating Help Chatbot, smooth scroll-reveal animations (`IntersectionObserver`), gold card glow elevation, and scroll-to-top button.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Library:** React 19
- **Styling:** Tailwind CSS (`#0B2545` Navy & `#C5A059` Antique Gold Design System)
- **Icons:** Lucide React
- **Language:** Strictly Pure JavaScript (ES Modules, JSX — No TypeScript)
- **Fonts:** Plus Jakarta Sans & Inter (via `next/font/google`)

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/DeveshYadav9107/School-Website.git

# Navigate into the project folder
cd School-Website

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deployment

This project is fully configured and deployment-ready for **Vercel** (`vercel.json`), **Netlify**, or Node servers (`npm run build && npm start`).
